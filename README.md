🍫 Chocolate Sales Data Analysis & Visualization
Welcome to the Chocolate Sales Data Analysis repository! This project explores and visualizes trends from a chocolate sales dataset using Python, with the help of libraries such as pandas, seaborn, and matplotlib.

📊 Project Overview
This project aims to:

Clean and preprocess sales data

Analyze total revenue, Country revenue, and product revenue

Generate clear and insightful visualizations to better understand sales performance
